# 三国志战略版起号流程记录

目标：从已登录状态启动游戏，进入普通 `赛季1` 最新区，并继续推进新手引导。

说明：账号密码不写入脚本和文档。登录续签、恢复角色、排队等弹窗作为状态机分支处理。

模板目录：`assets/templates/sgzz`

- `title_select_server.png`：标题页“点击选服”
- `title_enter_button.png`：标题页“前往征战”
- `restore_cancel_button.png`：恢复隐藏角色弹窗“取消”

## 已固化流程

入口命令：

```powershell
python main.py sgzz-select-latest-s1
```

排队时持续截图：

```powershell
python main.py sgzz-select-latest-s1 --queue-wait 300 --queue-poll 30
```

## 状态和点击点

| 状态 | 识别依据 | 动作 |
| --- | --- | --- |
| 启动游戏 | 包名 `com.aligames.sgzzlb` | `launch_package` |
| 更新/加载 | 无固定点击 | 等待标题页 |
| 恢复隐藏角色弹窗 | `restore_cancel_button.png` | 点取消 `(464,754)` |
| 标题页 | `title_select_server.png` | 点“点击选服” `(486,920)` |
| 选服弹窗 | `server_selector_title.png` | 进入底部赛季选择 |
| 赛季1短暂列表 | `season1_tab.png` | 快速点“赛季1” `(318,1036)`，默认点 2 次 |
| 普通 S1 最新服 | 赛季1后立即出现 | 立刻点左上第一服 `(185,219)` |
| 选服确认 | 选服弹窗底部按钮 | 点确定 `(360,1118)` |
| 标题页已选新区 | `title_enter_button.png` | 点“前往征战” `(360,1004)` |
| 服务器排队 | `queue_title.png` | 等待自动进入，不点退出 |

## 起号状态机节点

可查看节点：

```powershell
python main.py sgzz-flow-nodes
```

可从当前画面执行单个固定节点：

```powershell
python main.py sgzz-flow-node main_city_enter
```

| 节点 | 识别依据 | 动作 |
| --- | --- | --- |
| `select_latest_s1` | 标题页/选服弹窗/赛季1标签 | 启动游戏，进入普通赛季1最新服，点前往征战 |
| `old_man_intro` | `old_man_marker.png` | 老者在场时连续点继续；问答默认点顶部选项 |
| `create_character_xiliang` | 头像确认/进入乱世/落州页 | 确认头像，提交随机名，落州选择西凉 |
| `opening_dialogs` | `scout_marker.png` / `zhuge_marker.png` | 人物标记存在时连续点右下继续，直到人物消失或出现操作提示 |
| `recruit_free_twice` | 招募按钮/免费招募按钮 | 打开招募，点招募2次免费，关闭结果页返回地图 |
| `initial_team_config` | 城内部队一/部队配置页 | 曹休主将、孙乾副将、快速分兵，返回地图 |
| `first_occupy` | 教程高亮第一块地 | 点目标地，攻占，选择曹休队，确认出征，领取首占奖励 |
| `spear_config` | 选择主城/部队配置页/兵种选择 | 选择主城时点屏幕中心，入城，切枪兵，确认分兵，返回地图 |
| `support_ally` | “选择目标领地，支援义军” | 点高亮义军地，行军，选择曹休队，确认，战斗跳过，回城 |
| `reassign_main_after_support` | 部队配置页提示下阵曹休 | 下阵曹休，确认，再点主将位重新上阵 |
